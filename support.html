Quick setup guide

PayEcho pehli baar install kiya? Yeh steps follow karein:

App download karein

Google Play par jaayein aur PayEcho – UPI Mobile Soundbox install karein. Package: com.bhava.upialert

Notification Access allow karein

App open karein → Notification Access button tap karein → System settings mein PayEcho ko enable karein. Yeh permission bina kisi bank login ke sirf notification padhne ke liye hai.

Battery optimization off karein

Settings → Battery → PayEcho → Don't optimize select karein. Isse background mein alerts milte rehte hain.

Test payment karein

Koi bhi UPI app se ek chhota test payment receive karein — PayEcho automatically amount announce karega.
